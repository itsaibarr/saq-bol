- **t.me police/prosecutor posts** (dp_abai, dp_zhetysu, POLICE_of_KZ, GenPr): text verified against the public t.me/s channel export captured 2026-11-14; some posts are bilingual, and the Russian wording may be the police's own rendering of the scam text.
- **GitHub zenmoney/sms-formats** (most legit bank SMS/push): a public repo of real Kazakhstani bank SMS/push texts contributed as parser test cases. Not a bank/regulator page, so treat as a separate source type. `kind: push` rows contain the `║` separator the repo uses between push title and body. `published_date` is the file's commit date (date_confidence low/medium); the messages themselves are often older. Masked card tails like `*1234` were kept; full names/phones/card numbers were scrubbed.
- **ru2_090, ru2_091** were picked up from a parallel KK-slice agent's candidate file during an interim build (Otbasy/hcsbk.kz and informburo kk); they are Kazakh-language legit notices; at write time they did not duplicate any `kk2_collected.jsonl` row, but re-check if kk2 grows.
